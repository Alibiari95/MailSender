اتصال به Cloudflare Worker

آدرس Worker
راهنمای Deploy کردن Worker
  1. فایل worker.js رو دانلود کن
  2. به dash.cloudflare.com برو → Workers & Pages → Create
  3. کد رو paste کن و Deploy بزن
  4. در Settings → Variables این متغیرها رو اضافه کن:
FROM_EMAIL آدرس فرستنده — مثلاً hello@startup.com
FROM_NAME نام فرستنده — مثلاً تیم استارتاپ
API_SECRET یه رشته تصادفی برای امنیت
⚠️ برای اینکه MailChannels کار کنه، باید DNS record های SPF/DKIM دامنه‌ات رو تنظیم کنی. راهنما: developers.cloudflare.com/email-routing
